课程目标

  • 掌握自然语言处理的工作原理，能正确选择和使用恰当模型对不同类别文本进行分析处理，对词汇、句法层面的文本抽取和分类效果进行测试和分析，并能理解其局限性。
  • 能够根据实验方案构建实验系统，进行实验。
  • 能够在一定规模语料上选择合适的分词、词性标记、命名实体识别等算法，独立设计针对自然语言处理问题的相应解决方案。

课程简介

本课程是专业选修课，熟悉文本挖掘与自然语言处理将有助于个人数据分析能力的培养。 教学内容包括: 自然语言处理绪论；自动分词与词性标注；命名实体识别；自动句法分析；文本分类与情感分类；信息抽取与问答系统； 主要先修课程：面向对象的程序设计及 JAVA 语言、信息检索 考核与成绩记载方式：课程论文与实验相结合。

教学目的与要求

本课程系统介绍中文信息处理技术的原理和技术方法。通过学习，使学生对文本处理的一般知识、分词、词性标记、命名实体识别算法的设计有较深入的了解，能独立在一定规模的语料上开发中文信息处理相应的软件。学完本课程后，学生应具有下列几个方面的知识：
