课程目标

  • 理解数据库原理最基本概念和理论知识，了解数据库技术最重要的成果，熟练的运用数据库的基本知识、原理，识别、表达、分析复杂工程问题。
  • 熟练掌握关系模型和关系运算理论；掌握SQL语言；了解数据库安全性控制；熟练掌握关系数据库的规范化理论；掌握数据库设计方法；掌握数据库恢复的一般原理和方法。能够设计针对复杂数据库工程问题的解决方案，设计满足特定需求的数据库系统。
  • 能够采用数据库原理并采用科学方法设计数据库系统实验，能够使用数据库技术、资源和工具，对复杂工程问题进行实现。
  • 能够在数据库系统开发的团队中承担个体、团队成员以及负责人的角色。

课程简介

数据库原理及应用是为自动化大类专业学生开设的一门专业选修课，基于数据库的应用已经成为计算机应用的主流，数据库技术是数据管理最有效的手段，是构成信息系统重要基础。 本课程主要讲授SQL SERVER数据库管理系统基础理论与应用，介绍数据库的新技术和新应用，使学生掌握有关关系数据库的基本概念和基础理论。通过对本课程的学习，学生可全面深入地了解数据库系统的工作原理，掌握SQL语言应用的基本方法、编程语言与数据库的连接，数据库的编程设计，能够根据要求编写数据库程序并正确运行。 本课程的主要内容：（一）数据库基础理论：包括数据库系统概述、数据模型、关系数据库、数据库设计；（二）SQL SERVER数据库管理系统：包括 SQL Server 2008数据库管理、 SQL Server 2008数据表管理、数据查询与视图；（三）编程实例：包括Microsoft.NET及其开发工具、 Windows窗体编程、使用C#开发数据库。 预备知识：程序设计语言

教学目的与要求

《数据库原理及应用》以SQL SERVER为对象，通过课堂讲授、辅导答疑、上机实验等教学手段，使学生掌握数据库的基本知识、基本理论和基本方法，具有较强的数据库设计、数据库系统管理和应用开发能力。本课程旨在培养学生掌握数据库的管理与应用、数据维护、数据安全设置等技能。从单项技能培养的角度来说，本课程需要学生掌握数据库及数据表的创建与管理的方法，掌握数据完整性的实施方法，能实现对表中数据的维护与查询，能进行数据库安全设置和数据库管理的基本操作，掌握关系数据库的设计理论和方法。从综合技能的角度出发，需要学生掌握数据库应用系统的设计方法与思维能力，能根据实际需求进行数据库设计和综合应用开发。 通过数据库技术的发展与运用，增强学生民族自尊心、自信心和自豪感，激发学生科技报国的家国情怀和使命担当；通过课程中的马克思主义哲学思想，培养学生正确、规范的思维方式和分析方法；通过实践培养学生勤于动手、善于动脑，学思结合、知行统一，增强学生精益求精的工匠精神和不怕困难、勇于探索的创新精神。
