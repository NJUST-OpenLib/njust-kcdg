接口说明

按课程编号取数据，路径固定。已开启跨域（Access-Control-Allow-Origin: *），浏览器里可直接 fetch，无需代理。

用途路径说明
全量清单/index.json 全部课程条目，约 2 MB（gzip 后约 330 KB）。字段：code slug name nameEn credit dept active hasOutline
单课数据/json/{code}.json 基本信息 + 课程介绍 + 课程目标 + 章节内容与学时 + 教材 + 实验项目
纯文本/txt/{code}.txt UTF-8 带 BOM，记事本可直接打开
排版页面/html/{code}.html 渲染好的课程页面，含原始字段与全部大纲内容
原件镜像/original/{code}.html 源系统原始页面，仅 1,181 门有
 
# 取全量清单
curl https://kcdg.njust.store/index.json

# 取单门课程（以 10063001 数据结构 为例）
curl https://kcdg.njust.store/json/10063001.json
const list = await (await fetch('https://kcdg.njust.store/index.json')).json();
const hit  = list.filter(c => c.name.includes('数据结构'));
const data = await (await fetch(`https://kcdg.njust.store/json/${hit[0].code}.json`)).json();
  • 只能按课程编号精确取，没有搜索、筛选、分页接口；要搜索请拉 index.json 在本地过滤。
  • 12,991 门课程中仅 1,181 门有完整大纲，其余只有基本信息。
  • 有 1 门课程缺编号，它的路径是 /json/seq1.json。
  • 无鉴权、无限流、无可用性承诺；数据为快照，随时可能重新生成。请自行缓存，避免频繁拉取全量清单。

常见问题

为什么有些课程没有教学大纲？

源系统里这 12,991 门课程中只有 1,181 门录入了大纲，其余课程本身就没有上传，不是抓取遗漏。课程库里可以用「仅看有纲课程」筛选。

数据多久更新一次？

手工触发重新抓取，没有固定周期。当前快照日期为 2026-10-29，页脚会标注实际采集日期。

可以批量下载吗？

可以，但不提供打包文件。先取 /index.json 拿到全部课程编号，再按 /json/{code}.json 逐个请求即可，建议控制并发、做好本地缓存。

发现内容有误或想提建议？

请发邮件到 lingyu_04@outlook.com，附上课程编号和具体问题。原始内容的错误需要回到教务系统更正，镜像只能跟着源数据走。
